## How do element flow, keystrokes and SmartType behave while typing?

### Takeaway
Writing runs on Tab and Enter/Return, and every element has a defined Tab target and Enter target. The status bar always shows those two targets as a live hint. Pressing Enter on an empty line opens a floating element picker with single-letter keys. Holding Cmd (Mac) or Ctrl (Win) shows numbered shortcuts that change with context. SmartType pops a list after the first letter in a scene heading (INT./I/E, then the time of day) and in transitions.

### Cited Findings
- The FD13 main window has four areas: menu bar, toolbar, page and status bar. The status bar shows, left to right: page "x of y", the current scene ("No Scene" before any heading), a centred hint, then a sprint-timer icon, a microphone icon, a focus (reticle) icon, a moon (appearance) icon, a zoom slider and the zoom percentage — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw)
- The hint changes with the element and with whether the line is empty. Examples seen:
  - non-empty Action: "[Tab] Action, [Enter] Action, [Cmd] hold for Elements"
  - empty Action: "[Tab] Character, [Enter] Select Element…"
  - typing the location in a heading: "[Tab] Select Location, [Enter] Action…"
  - Dialogue: "[Tab] Parenthetical, [Enter] Action…"
  - Shot: "[Tab] Shot, [Enter] Action"
  — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk); [QS12](https://www.youtube.com/watch?v=F4Uj_L6K56c)
- In a blank screenplay, typing "I" in a Scene Heading opens a small "SmartType" list (INT., I/E) with INT. highlighted, and the rest of the word appears as grey inline completion. Tab accepts it. After the location, Tab inserts the " - " separator and opens a time-of-day list: DAY, NIGHT, AFTERNOON, MORNING, EVENING, LATER, MOMENTS LATER, CONTINUOUS, THE NEXT DAY, MAGIC HOUR, DAWN, DUSK, SAME, SAME TIME. You can pick with the arrow keys, the first letter (N picks NIGHT) or the mouse. Tab again commits the heading, capitalises it and moves to Action — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [QS12](https://www.youtube.com/watch?v=F4Uj_L6K56c)
- Element flow shown in the demos:
  - Enter after Action gives another Action. Tab on an empty Action changes it to Character.
  - Enter after Character gives Dialogue.
  - Tab inside Dialogue inserts a Parenthetical, with the parentheses added automatically. Enter after the parenthetical returns to Dialogue.
  - Enter after Dialogue gives an empty line. A second Enter on that empty line opens the element picker.
  — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [QS12](https://www.youtube.com/watch?v=F4Uj_L6K56c)
- The element picker (titled "Elements") floats under the cursor with the current element highlighted. Its keys: [G] General, [S] Scene Heading, [A] Action, [C] Character, [P] Parenthetical, [D] Dialogue, [T] Transition, [H] Shot, [L] Cast List, [N] New Act, [Q] Sequence, [E] End of Act, [0] Summary, [1] Outline 1, [2] Outline 2, [3] Outline 3, [4] Note. Arrow keys plus Enter also work — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [OEl13](https://www.youtube.com/watch?v=nk73fnWxx_s)
- Holding Cmd (Mac) or Ctrl (Windows) replaces the hint with numbered shortcuts. In script text: "[0] General [1] Scene Heading [2] Action [3] Character [4] Parenthetical [5] Dialogue [6] Transition [7] Shot [8] Cast List [9] New Act", followed by a note that Cmd+Control held shows more elements. Pressing Cmd+number inserts that element; the demo used Cmd+7 to insert a Shot. Inside outline paragraphs the numbered set changes to "[0] Summary [1] Outline 1 [2] Outline 2 [3] Outline 3 [4] Note [8] Sequence [9] End of Act" — [QS12](https://www.youtube.com/watch?v=F4Uj_L6K56c); [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI); [OEl13](https://www.youtube.com/watch?v=nk73fnWxx_s)
- Transition SmartType: typing "DIS" in a Transition shows a SmartType list offering "DISSOLVE TO:" (Windows demo) — [QS12](https://www.youtube.com/watch?v=F4Uj_L6K56c)
- The toolbar "Elements" pop-up in FD13 lists General, Scene Heading, Action, Character, Parenthetical, Dialogue, Transition, Shot, Cast List, New Act, Sequence, End of Act, Summary, Outline 1, Outline 2, Outline 3 and Note, with a check mark on the current element. Renamed outline lanes appear under their new names (e.g. "Outline 1 (Acts)", "Outline 3 (Scenes)") — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk)
- The FD13 right-click menu in script text has: Undo Typing; Cut, Copy, Paste, Delete, Select All; Change Element To ▸ (full element list); Insert ScriptNote; Insert Non-Speaking Character; Insert Image…; spelling suggestions; Thesaurus. After a change it also offers "Undo Element Change" or "Undo Color Change", and on scene headings a "Scene Color ▸" submenu — [QS13](https://www.youtube.com/watch?v=gd0oc1RQsGw); [SL13](https://www.youtube.com/watch?v=bzMgRoAX1i4); [Ref12](https://www.youtube.com/watch?v=oMLL6bD-o5M)
- Automatic "(CONT'D)" appears on a character cue when the same speaker resumes after an intervening Action (e.g. a second UNCLE speech becomes "UNCLE (CONT'D)"). This was visible throughout the FD12 and FD13 demo scripts — [TW13](https://www.youtube.com/watch?v=Xcb8j5rKfto); [NavC13](https://www.youtube.com/watch?v=TUIs7PsAudU)
- The Elements dialog (Format > Elements…) sets each element's "Next Element (Enter/Return)" target and a "Hold Cmd+Ctrl + [key]" shortcut (Windows: Ctrl+Shift+[key]). The defaults shown were General → 0, with the next element after General being General — [CE12](https://www.youtube.com/watch?v=aTGzdXgp_VQ)

### Inferences
- The hint's wording suggests a per-element table with the fields {tab_target, enter_target, empty_line_tab_target, empty_line_enter = open picker}. Implementing that table data-first would let the hint text be generated from it.
- The Cmd/Ctrl numbered shortcuts depend on whether the caret is in an outline or a script paragraph, so this is a context-sensitive keymap rather than a fixed one.

### Gaps
- No official FD11–13 video demonstrates the SmartType list editor (Document > SmartType…), character-name SmartType from earlier cues, or how SmartType learns new locations. The menu item exists ([WM12](https://www.youtube.com/watch?v=LhU6oztbXEE) frames), but its dialog was not shown.
- No video demonstrates the Tab behaviour from Character to a parenthetical, or the full Transition/Shot flows beyond what is noted above.

## How do the Navigator 2.0, Index Cards and Scene View behave?

### Takeaway
FD13's Navigator is a floating, pinnable window of customisable tabs (Script, Characters, ScriptNotes, plus duplicates you can rename). Each tab can be filtered, and there is a global search, CSV export and a Reports button. The Script tab doubles as a structural outliner: you edit cells in place, and dragging a row moves the whole structural range unless Option/Alt is held. Index Cards and Scene View remain in the View menu as alternative script views.

### Cited Findings
- A new file opens with one "Script" tab, which combines FD12's Scenes and Tags tabs. Default columns are Order, Page, Script, Color and Summary. The Script column works as a table of contents: every structure paragraph (act, outline, sequence, scene heading), indented by level. Summary-column text appears in the script as Summary outline paragraphs under that structure paragraph, and hides when the outline is hidden — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- The column chooser (button at the right) offers Order, Color, Intro, Length, Location, Page, Scene #, Time, Title, Script, Summary, Tags and Tag Categories, plus expandable groups for Characters, Character Arcs, Tags and Tag Categories. You can resize the window and columns and drag headers to reorder — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- Editing in place: click a row, then click the field again to edit; clicking away commits and the script updates. The Color cell is a pop-up of named colours (e.g. "Purple") — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- Reordering: clicking a structure row draws a "scope frame" around its whole range. Dragging shows a shaded scope plus a drop indicator, and the parent moves with all its children. Holding Option (Mac) or Alt (Win) while dragging moves only that row — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- Tabs: "+" opens a menu to add a Characters, ScriptNotes or Script tab (duplicates allowed). Tabs can be renamed, reordered, and closed with an X shown on hover. Each tab has its own filter field (e.g. a character name). The magnifier opens a global search across all tabs, and the two combine. The Export button saves the current tab as CSV. The Reports button opens the reports menu — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- Scene columns seen in a shooting script:
  - Intro: INT/EXT
  - Location
  - Time, with story-day codes such as "DAY (D5)", "NIGHT (N4)", "DAY/CONTINUOUS (D6)"
  - Length in eighths of a page (e.g. 1 2/8, 3/8)
  - tag-category columns (Makeup/Hair, Props)
  - scene numbers including A-numbers (7A)
  — [NavS13](https://www.youtube.com/watch?v=-fcvGetFg4g)
- Characters tab: one row per cue name, including group cues such as "TANGLE & MOSSY". Columns are Character, Highlight Color, Highlight Dialogues (checkbox), Voice (text-to-speech voices such as "Man 1", "Woman 2", "Old Woman", "Girl 1"), Dialogues, Scenes, Speaking Scenes and Non-Speaking Scenes. Ticking Highlight Dialogues paints that character's cue and dialogue in the highlight colour on the page. Renaming a character cell renames every cue in the script, including the (CONT'D) cues — [NavC13](https://www.youtube.com/watch?v=TUIs7PsAudU)
- Character Traits: the defaults are Age, Disability, Ethnicity, Gender, Occupation, Orientation and Role. An edit mode lets you add ("New Trait"), rename and delete traits; custom examples were Arc, Flaw and Goal. Trait cells are combo pop-ups. An Inclusivity Analysis panel has Trait 1 / Trait 2 pop-ups and three nested donut charts: Characters, Dialogue, and scenes with at least one character whose Role is Lead. It reports an "Unassigned" share — [NavC13](https://www.youtube.com/watch?v=TUIs7PsAudU)
- In FD11 the Navigator opens from the toolbar button or Tools > Show Navigator (Windows: View > Show Navigator). A pin icon keeps it floating in front of the script — [TagW11](https://www.youtube.com/watch?v=AfhdpIQnu0I); [NavSN11](https://www.youtube.com/watch?v=XAzS0O7-0Gk)
- The FD13 View menu still lists "Index Cards - Script", "Index Cards - Summary", "Cards Across ▸", "Scene View" and "Show/Hide Scene View ▸", next to "Script - Normal View", "Script - Page View" (default) and "Script - Speed View" — [TW13](https://www.youtube.com/watch?v=Xcb8j5rKfto)
- Index card behaviour, from the legacy FD9 video (the same menu items survive in FD13):
  - Each card shows the scene heading in its title bar and the page number at the right (e.g. "p.1"). The body shows either the summary or the script text, depending on the view.
  - The card is tinted with the scene colour. Cards Across picks 1–9 columns.
  - Dragging a card reorders the scenes in the script.
  - Right-clicking a card offers Summary View / Script View, Insert New Scene (adds a card with an "Add Scene Heading" placeholder), Insert Non-Speaking Character, Send to Script, and colours None, Red, Orange, Yellow, Green, Blue, Purple, Grey.
  - Summary text typed on a card also shows in the Navigator's summary field.
  - Scene View lists scenes as rows (heading, first action line, bold title, summary). Its right-click menu has Hide Action, Hide Scene Title, Hide Summary and Insert New Scene.
  — [IC9](https://www.youtube.com/watch?v=z2UY-TtBZxY)
- A FD13 Index Cards - Summary demo showed cards with the coloured heading, the page at top right ("p.1", "p.2") and the summary text in colour, beside the script in split view — [OEl13](https://www.youtube.com/watch?v=nk73fnWxx_s)

### Inferences
- The Navigator is a grid over structure paragraphs, with per-tab column sets and filters. Storing tab definitions (type, name, visible columns, filter text) per document would reproduce it.
- Range-drag (moving a parent with its children) versus single-row drag (Option/Alt) is a key interaction detail to copy.

### Gaps
- No captions were published for the Characters video, so the Voice column's purpose is inferred from the Tools > Assign Voices… menu and the voice names (text-to-speech read-back).
- I found no FD12/FD13 video dedicated to Index Cards or Scene View. Their current behaviour may differ from the FD9 demo.

## How do the Beat Board, Outline Editor, Story Map, outline elements and Structure Lines work?

### Takeaway
Planning flows Beat Board → Outline Editor lanes (with page-goal ranges) → "Send Outline to Script". Beats become Outline 1/2/3 paragraphs with Summary bodies, nested, coloured and drawn with structure lines. Outline paragraphs are a non-printing planning layer you can hide, and hiding them changes the pagination.

### Cited Findings
- Beat Board: open it from View > Beat Board, the toolbar button (Mac) or the Home/View ribbon (Windows).
  - New beat: Cmd+Return (Mac), Ctrl+Enter (Win), or double-click empty board. Dropping an image creates an image beat. Dragging copied script text creates a beat that keeps the script formatting.
  - The caret starts in the Title field ("Beat Title" placeholder); Tab moves to Body ("Body" placeholder). Drag the edges to resize.
  — [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI)
- Beat right-click menu (FD13):
  - Align Selected ▸ (To Grid, Make Column, Make Row, Cascade)
  - Send to Script
  - Remove Outline Goal (enabled only once the beat is placed in the Outline Editor)
  - Cut / Copy / Paste
  - colour swatches (none, about 13 colours, and a custom colour that opens the system colour picker)
  - Beat Shows ▸ (Title and Body, the default; Title Only; Body Only — the single-field views use larger text)
  - Connect ▸, Connection Color ▸, Disconnect (flow lines)
  — [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI)
- Beat selection and editing:
  - Lasso-select by dragging; Cmd/Ctrl+click adds to the selection. Groups move without losing their relative positions.
  - Copy/paste duplicates a beat with its size, font style, colour and view.
  - Find/Replace (Cmd/Ctrl+F) searches beats and scrolls the board to the hit. Edit > Rename Character renames on the board too.
  - The board has the Day/Night/Midnight appearance and a zoom slider, and can be exported to PDF.
  — [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI)
- Beats placed in the Outline Editor show a "Goal: x – y" page range in their top-right corner on the Beat Board (e.g. "Goal: 21 – 21⅛"). The range updates live when the goal is moved or resized — [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI); [OE13](https://www.youtube.com/watch?v=eGY4JQ77oWU)
- Outline Editor layout and goals:
  - Toggle it from the View menu (Show Outline Editor, Shift+Cmd+M). It is a horizontal strip above the script or board, resized by dragging its bottom edge, with its own zoom slider ("Zoom Outline Editor").
  - Lane labels down the left: "Outline 1 (Acts)", "Outline 2 (Sequences)", "Outline 3 (Scenes)", then a "Script" lane that shows the actual scenes as abbreviated heading blocks against a page ruler.
  - Dropping a beat in a lane gives it a ½-page goal by default. Goals resize down to ⅛ page and drag to new pages. Clicking a goal opens an editable title/body preview that stays in sync with the board.
  — [OE13](https://www.youtube.com/watch?v=eGY4JQ77oWU); [TW13](https://www.youtube.com/watch?v=Xcb8j5rKfto)
- Outline Editor hierarchy and lane menu:
  - Beats in Outline 1 are parents of the Outline 2 beats whose ranges start beneath them; moving a parent moves its children.
  - Hovering a lane label reveals "…". Its menu has Add Lane ▸ (copies of existing levels such as "Outline 1 (New)", "Outline 2 (New)", "Outline 3", or "New Outline Element…"), Remove Lane, Indent, Outdent, Rename, Move Lane Up/Down, Change Element ▸ and Format… (opens the element formatting dialog).
  - Each lane is an outline element, so renaming a lane (or clicking its label and pressing Return) renames the element in the Elements menu. Lanes are unlimited, e.g. one Outline 3 lane per character storyline.
  — [OE13](https://www.youtube.com/watch?v=eGY4JQ77oWU); [Lanes13](https://www.youtube.com/watch?v=jVjgCIbZBJE)
- Right-clicking the Outline Editor background offers New Beat, Change Target Script Length… and Hide Outline Editor. The "Target Script Length" dialog has one number field. Ruler page numbers past the target turn red. Setting 100 turns each mark into 1% — [OE13](https://www.youtube.com/watch?v=eGY4JQ77oWU); [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk)
- "Send Outline to Script" is a single button in the Outline Editor's left panel. Lane beat titles become Outline 1/2/3 paragraphs and beat bodies become Summary paragraphs, nested under their parents. Afterwards the Script lane reflects the script. Context-menu "Send to Script" on Beat Board beats inserts them in selection order as outline paragraphs — [OE13](https://www.youtube.com/watch?v=eGY4JQ77oWU); [SOS13](https://www.youtube.com/watch?v=k6Gb53paW6Y); [BB13](https://www.youtube.com/watch?v=3eUwfuu2IcI)
- The intended 1-2-3 workflow:
  1. Brainstorm act and sequence beats joined by flow lines.
  2. Drag the act beats to lane 1 and the sequence beats to lane 2, then set the target length (28 pages in the demo).
  3. Send to script. Split the Summary text into Outline 3 (scenes) and Note paragraphs, write scenes underneath, and finally convert the outline paragraphs to real elements (Outline 2 → Sequence, Outline 3 → Scene Heading, Notes → Action/Character/Dialogue).
  — [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk)
- Outline element styling in FD13:
  - Summary: coloured general text
  - Outline 1: large and bold
  - Outline 2 and Outline 3: progressively smaller and more indented
  - Note: italic and indented
  - all in a distinct (blue/purple) colour, separate from the Courier script elements
  - Sequence: bold, underlined capitals
  - Hints: in Summary, "[Tab] Summary, [Enter] Summary"; in a Note, "[Tab] Outline 1, [Enter] Select Element"
  — [OEl13](https://www.youtube.com/watch?v=nk73fnWxx_s); [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk)
- The Show/Hide toolbar menu has Hide Outline Editor, Show Ruler, Hide Outline in Script, Hide Structure Lines, Hide ScriptNotes, Hide Alts. and Show Invisibles. Hiding the outline removes the outline paragraphs from the page and repaginates (the same script showed "1 of 49" before and "1 of 41" after). In collaboration everyone should use the same setting so page counts match — [123-13](https://www.youtube.com/watch?v=Zhxw-pDGUbk); [OEl13](https://www.youtube.com/watch?v=nk73fnWxx_s); [Collab12](https://www.youtube.com/watch?v=KaNDvz-ENA4)
- Structure Lines:
  - Right-click a structure paragraph (outline, act, sequence or scene heading) and pick a colour, or set it in the Navigator Script tab's Color column.
  - A vertical coloured line in the left margin then spans that paragraph and all its children; nested levels draw parallel lines.
  - Hide them with View > Document > Hide Structure Lines (Mac), View > Hide Structure Lines (Win), or Show/Hide > Show Structure Lines. A "Structure Lines" toolbar button is available.
  - Visible lines are printed and included in PDFs.
  — [SL13](https://www.youtube.com/watch?v=bzMgRoAX1i4)
- Story Map (FD11, the predecessor to the Outline Editor):
  - A page strip. Dragging a beat onto a page drops an icon in the beat's colour below that page number. Hovering previews the title, body and image; double-clicking jumps to the beat on the Beat Board; dragging changes the page goal. Several beats on one page show a count.
  - "Structure points" appear as square markers above the page numbers.
  - Scene colours show as a horizontal band; double-clicking a segment jumps to that page.
  - Target Script Length works as in the Outline Editor (overflow pages in red).
  - A vertical blue line tracks the caret's page.
  - Page goals are for planning only and are not bound to real pages.
  — [SM11](https://www.youtube.com/watch?v=qqfBune8np0)

### Inferences
- The data model implied is beats (title, body, image, colour, view mode, board position and size, optional {lane, start page, length}), lanes (outline-level element, name, order, indent) and a document target length. "Send Outline to Script" is a one-way generator, not a live link.

### Gaps

## How do Revision mode, revision colours, Lock Pages / A-pages and scene numbering behave?

### Takeaway
Revisions are managed in one "Revision Mode" dialog. Overflow then creates A-pages, with lettering that deepens (A, AA, AAA) each time the pages are relocked, and Locking Tools adjust page numbers manually.

### Cited Findings
- Production > Revisions… opens the "Revision Mode" dialog, with a "Revision Mode" checkbox in its title row and the instruction to double-click a set to activate it and drag to reorder.

  - Buttons: +/−, a gear (edit), "Previous Revision Set" and "Next Revision Set".
  — [Rev12](https://www.youtube.com/watch?v=mwlxQVmi2tU)
- Dialog options:
  - "Show page colors" checkbox: tints the page margins on screen in the set colour.
  - "Show text and marks:" pop-up: From Active Revision Set Only (default), Collated Script, From All Revision Sets, From All Revision Sets After and Including Latest Full Draft, None.
  - "Mark location:" stepper, showing 7.750".
  — [Rev12](https://www.youtube.com/watch?v=mwlxQVmi2tU)
- "Edit Revision Set" sheet (gear button):
  - Label: the user replaces mm/dd/yy with a date, e.g. "Blue Rev. (03/07/21)"
  - Page color pop-up: White, Blue, Pink, Yellow, Green, Goldenrod, Buff, Salmon, Cherry, Tan
  - Show on: Revised Pages Only / Full Draft
  - Text style: Bold, Underline, Strikethrough toggles plus a colour well
  - Underline style (Regular…)
  - Mark: text field; the demo changed "*" to "*B" and "*P"
  — [Rev12](https://www.youtube.com/watch?v=mwlxQVmi2tU)
- With Revision Mode on, new or changed text takes the active set's text colour and the mark appears in the right margin of each changed line. Revised pages carry a header with the set label to the left of the page number (e.g. "Blue Rev. (03/07/21)   4."), and the status bar shows the active set label — [Rev12](https://www.youtube.com/watch?v=mwlxQVmi2tU); [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)
- FD12 Production menu: Scene Numbers…, Edit Scene Number… (Shift+Cmd+J), Omit Scene, Revisions…, Revision Mode (toggle), Mark Revised (Cmd+]), Clear Revised (Cmd+[), Lock Pages, Lock "A" Pages, Unlock "A" Pages, Unlock All Pages, Locking Tools ▸, Tags Mode (Shift+Cmd+T), Tag All Characters — [Rev12](https://www.youtube.com/watch?v=mwlxQVmi2tU); [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)
- Locking:
  - Production > Lock Pages asks for confirmation; Yes locks every page and turns Revision Mode on. A lock icon appears at the top right of each locked page.
  - Text added later is drawn as revised. Overflow from page 10 creates "10A" while page 11 stays put.
  - Lock "A" Pages protects the current A-pages; the narrator advises saving a new file at each relock, usually with a new revision set.
  - Unlock "A" Pages releases the latest set, so AA pages become B (10A → 10B).
  - Unlock All Pages renumbers consecutively (10A → 11) and keeps all content. Scene numbering is unaffected.
  — [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)
- Narrated numbering rules:
  - Pages inserted after locked page 2 are 2A, 2B, 2C in the first lock set; 2AA, 2AB, 2AC in the second; 2AAA, 2AAB, 2AAC in the third.
  - After a whole page, in any set, a new page is simply "3A".
  - Pages added past the last page continue straight (100 → 101, 102) but are marked revised.
  - A locked page emptied of text stays as a blank page. Double-clicking it to select it and pressing Delete merges its number into the previous page as "2-3".
  — [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)

  - Adjust Locked Page: a dialog listing valid page numbers, from which you pick where the current paragraph should begin.
  - Edit Locked Page: a manual override that bypasses the locked-page counting logic; flagged as not recommended.
  - Lock New Page: locks from the insertion point to the end of that page.
  - Unlock Page: removes the page's bottom boundary so text flows back from the next page.
  - Relock Pages: strips A-numbers from the insertion point onward (110, 110A, 110B, 111 → 110, 111, 112, 113).
  — [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)
- Locking does not cheat the page count and does not password-protect the file — [Lock12](https://www.youtube.com/watch?v=J3fU9beJxHo)

- A title page can carry a revision history block (one line per colour and date), shown in the PDF-import demo — [PDF12](https://www.youtube.com/watch?v=EP6xToT3ukE)

### Inferences

## How do ScriptNotes, Track Changes and Collaboration behave?

### Takeaway
ScriptNotes are anchored to selected text, marked by coloured margin bubbles and listed in a Navigator tab with types and colours. Track Changes colours each writer's edits (name and colour come from Preferences) and offers per-change Accept/Reject popovers. Collaboration is a real-time, host-and-join session using a Session ID. Notes and beats lock while someone edits them, and nothing is stored on a server.

### Cited Findings
- Insert a ScriptNote with Shift+Cmd+K (Mac) or Ctrl+J (Windows); both overlays are shown on screen in FD13. It is also on the context menu ("Insert ScriptNote") and Insert > ScriptNote — [SN13](https://www.youtube.com/watch?v=IUxYt0UrnI8); [NavSN11](https://www.youtube.com/watch?v=XAzS0O7-0Gk)
- Note markers and popover (FD13):
  - The marker is a small coloured speech-bubble in the right margin. Several notes on one line show a number. Hovering shows the tooltip "Show ScriptNote"; clicking highlights the anchored text and opens the popover.
  - Popover header: author name, date/time and a trash icon. Fields: Title and Body (placeholders). Footer: colour swatch, Type pop-up (None, All Scenes, On Character, Producer, Writer, New Type…) and ‹ › to step to the previous or next note.
  — [SN13](https://www.youtube.com/watch?v=IUxYt0UrnI8)

  — [SN13](https://www.youtube.com/watch?v=IUxYt0UrnI8)
- Markers never print or appear in PDFs. Double-clicking a marker opens the Navigator. FD11 also had General Notes, which belong to the whole document rather than a paragraph, sit at the top of the list and are coloured and categorised the same way. - Track Changes:
  - Edit > Track Changes > Turn On Tracking; the toolbar Track Changes button turns green.

  - Everyone can edit at once, on different pages. The host can turn on tracking; changes then appear in each collaborator's session colour, and afterwards revert to each writer's own preference name and colour.

Its options include: characters should have dialogue, precede a dialogue and not have consecutive dialogues; elements should not start with blank space and should not be empty — [Ref12](https://www.youtube.com/watch?v=oMLL6bD-o5M); [PDF12](https://www.youtube.com/watch?v=EP6xToT3ukE)
- FD13 Mac File menu: New, New from Template…, Open…, Open Recent ▸, Close, Save, Save As…, Save As PDF…, Export ▸, Backup…, Revert, Save as Template…, Print Preview, Print…, Register Script, Get Notes — [CPDF13](https://www.youtube.com/watch?v=GUrb55-iJ3E)
- Windows Open dialog file types: Final Draft Documents (*.fdx, *.fdxt), Final Draft 5-7 Documents (*.fdr, *.fdt), Plain Text (*.txt), Rich Text (*.rtf), File Converter Documents (*.fcf), PDF Documents (*.pdf), All Files — [Word12](https://www.youtube.com/watch?v=WEFaDaK-YgI)
- TXT/RTF import: File > Open (on Windows, set the file type) and choose to import as a screenplay. Expect misassigned elements: headings typed as Action, names as Dialogue, and paragraphs run together — [Ref12](https://www.youtube.com/watch?v=oMLL6bD-o5M)
- PDF import: File > Open a PDF. It converts with scene numbers and story-day suffixes kept, and the title page becomes a real title page (including the revision history). Some elements come in misassigned (e.g. a Shot read as a Character) and are fixed with the Reformat palette. Save the result as .fdx — [PDF12](https://www.youtube.com/watch?v=EP6xToT3ukE)
- Word import demo: save in Word as .docx, then bring it into Final Draft. Visible side effects included curly apostrophes turning into wrong characters in the imported text, which then needed Reformat — [Word12](https://www.youtube.com/watch?v=WEFaDaK-YgI)
- Reformat palette (Tools > Reformat…):
  - Shows "Selected: <element>" and "Change element to:" with numbered keys: 0 General, 1 Scene Heading, 2 Action, 3 Character, 4 Parenthetical, 5 Dialogue, 6 Transition, 7 Shot, 8 Cast List, 9 New Act, Ctrl+9 End of Act, Ctrl+0 Outline Body, Ctrl+1–4 Outline 1–4 (the FD12 list).
  - Buttons: Delete, ‹ and ›.
  - It highlights one paragraph at a time and moves on after each change. It cannot split run-together paragraphs; you press Return to separate them first.
  — [Ref12](https://www.youtube.com/watch?v=oMLL6bD-o5M)
- Auto-save and backup:
  - Every save and every auto-save writes a date- and time-stamped backup into a backup folder. The default limit is 1,000 files, up to 10,000; the oldest is purged first.
  - Mac Preferences > Auto-Save/Backup: "Auto-Save every [n] minutes" (5 in the demo), "Ask before Auto-Save", "Auto-Backup enabled", the file limit, Open Backup Folder and Select New Folder. Windows defaults seen: auto-save every 15 minutes, 1,000 backups.
  - The backup folder can live in a cloud-synced folder. To restore, open a backup and save it under a new name.
  — [AS12](https://www.youtube.com/watch?v=JPCrWx8gOfs); [TC12](https://www.youtube.com/watch?v=2owyLjFylqM)

## What is new in FD12 and FD13 (writing stats, typewriter, focus, emoji, appearance), and what does the Cloud show?

### Takeaway
FD13 added Navigator 2.0, Structure Lines, custom script colours and colour PDFs, Beat Board "Beat Shows", custom Outline Editor lanes, Emoji, Typewriter view, Midnight Mode and Writing Stats. FD12 added the Outline Editor, Track Changes, Focus Mode, dual-dialogue editing, Night Mode and the improved collaboration and ScriptNotes. Final Draft Cloud is a browser writer with SmartSave and threaded ScriptNotes.

### Cited Findings
- FD13 headline list: customisable script colours, Structure Lines, dialogue highlighting from the Navigator, custom beat views, custom lanes, Emoji, Typewriter, Midnight Mode, Navigator 2.0 tabs and reports, Writing Stats, and the Final Draft Go app for iPhone/iPad — [New13](https://www.youtube.com/watch?v=-EUksm04ov4)

- Writing Stats dashboard:
  - Open from Tools > Writing Stats or the toolbar button.
  - Tiles: Current Streak, Longest Streak, Peak Days, Peak Times. Segmented controls switch between Words, Pages and Time and between Day, Week, Month and Year, with a total or average and a bar chart.
  - "Time out after [3] minutes" ends a session after inactivity; any activity starts a new one.
  - "Set Goals" opens "Writing Goals": [#] pages per [Day|Week|Month|Year], [#] words per [period], [#] [Minutes|Hours] per [period]. OK stays disabled until something is entered. A goal line is drawn over the chart with a label such as "Goal: 3 pages / day".
  - The status-bar Sprint Timer now has a stopwatch as well as the countdown (default 25 minutes), plus Start Sprint and Show Stats (current-session pages, words and time).
  — [WS13](https://www.youtube.com/watch?v=tis7MnjQc7o)
- Typewriter: View > Typewriter > Enable keeps the active line fixed on screen and scrolls the page instead. Indicator options are Line (default; a rule under the active line), Frame (a box around it) and None. It works in every theme. A toolbar button exists on Mac; on Windows use the View ribbon "Typewriter Mode" — [TW13](https://www.youtube.com/watch?v=Xcb8j5rKfto)
- Focus Mode: the reticle icon on the status bar, or View > Focus Mode. It hides the Navigator, Outline Editor and ruler and goes full screen (Mac) or maximised (Windows). On Mac, hovering at the top reveals the toolbar. You can leave full screen while staying in focus mode. Clicking the reticle again restores everything — [Focus12](https://www.youtube.com/watch?v=L2amsIZrFrI)
- Emoji: Edit > Emoji & Symbols (Mac Character Viewer, Windows emoji panel), or Cmd+Ctrl+Space on Mac. Allowed in script text, beats (also shown in the Outline Editor) and ScriptNotes. Emoji are in full colour on Mac and monochrome on Windows, where Format > Text Color can tint them. An Emoji toolbar button is available — [Emoji13](https://www.youtube.com/watch?v=O727ARWI4Zk)
- FD13 Mac Tools menu: Spelling…, Thesaurus…, Speech Control…, Assign Voices…, Reports ▸, Combine Files…, Names Database…, Reformat…, Format Assistant…, ScriptCompare…, Show Navigator, Collaboration…, Sprint Timer…, Writing Stats… — [NavC13](https://www.youtube.com/watch?v=TUIs7PsAudU)
- FD13 Mac Help menu: Get Support, Submit Feedback, Learn, Final Draft User Guide, Welcome to Final Draft, What's New, Sample Scripts ▸, Check for Updates, Sign Out…. FD12 had Register Online and Deactivate… in place of Sign Out — [TW13](https://www.youtube.com/watch?v=Xcb8j5rKfto); [TP12](https://www.youtube.com/watch?v=vIVBLrZPLms)
- Final Draft Cloud (browser):
  - Settings has Account, Profile, Preferences, Notifications and Address Book. Preferences: Theme (Day/Night/Midnight), Auto-Save Cadence "Auto (SmartSave)", Default Template ("Screenplay for Beginners"), Recent Items 15, Show Format Palette (Yes/No).

  — [Cloud](https://www.youtube.com/watch?v=QhUVP5cd9kY)
