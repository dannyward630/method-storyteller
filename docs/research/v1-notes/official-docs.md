# Final Draft 11 / 12 / 13 — functional inventory from official documentation (for Method Storyteller V1.0 scoping)

Conventions used throughout:
- **Ver** = earliest version in which the feature is documented, from comparing the official FD11 (11.1.6), FD12 and FD13 user guides and the official release-notes pages. "≤11" means it is already in the FD11 guide (it may be older than 11). "11.0.2", "12.0.4", "13.3.3" etc. come from the official release notes.

## Q1. What do the official FD11/12/13 user guides cover, menu by menu?

### Takeaway
The FD13 guide is organised by menu (Mac: Final Draft, File, Edit, View, Format, Insert, Document, Tools, Production, Window, Help; Windows uses ribbons named after the same menus plus a "Classic View" menu bar), followed by topic chapters (Elements, Beat Board/Outline Editor, Navigator, Panels, Tagging, Toolbar/Status bar, Header & Footer, Reformatting, SmartType, Shortcuts, Language, Glossary). The core a clone must match is: the File/Export set, Edit find/replace/go-to, the three script views, Format > Elements, Document > Page Layout / Header & Footer / Mores & Continueds / Title Page / SmartType, and the Production menu.

### Inferences
- The manuals are nearly identical between Mac and Windows in behaviour; differences are chrome (ribbon vs menu bar), shortcut modifiers (Cmd vs Ctrl), backup caps, and a few OS-integration items (dictation, emoji picker, window tabs). A Rust clone can treat one behavioural spec as authoritative and skin per OS.
- Several FD operations are documented as not undoable (Replace All, Rename Character, Navigator row drag, Reformat-tool Delete, alt delete, unlocking pages). Making these undoable is an easy quality win for a clone.

### Gaps
- The manuals do not enumerate every toolbar/ribbon icon or every context-menu entry; a complete UI-element map would require running the product, which this clean-room exercise avoids.
- No official document lists which features differ in FD Go (iPad/iPhone) at menu level; only marketing bullets were found (Q8).

## Q2. Elements and SmartType: defaults, Tab/Enter flow, SmartType lists, extensions, auto-capitalisation

### Takeaway
A script is a stack of typed paragraphs ("elements"). The core, non-deletable elements are General, Scene Heading, Action, Character, Parenthetical, Dialogue, Transition, Shot and Cast List; templates add New Act, End of Act, Sequence and the outline elements (Summary, Outline 1–3, Note). Return and Tab each map "current element → next element" (user-editable for Return), and SmartType autocompletes six lists (characters, extensions, scene intros, locations, times, transitions). This flow is the heart of the product and is **v1** almost in its entirety.

### Cited Findings
- **Core elements and their semantics** (all Ver ≤11; Tag **v1**) — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.17.1, §1.17.3:
  - General: catch-all text.
  - Scene Heading: always uppercase; has three sub-parts (intro INT/EXT/I/E, location, time of day); the only element normally numbered; never left orphaned at a page bottom (moves to the next page with following action).
  - Action: description.
  - Character: always uppercase, precedes dialogue; may carry an extension in parentheses.
  - Parenthetical: brief direction; FD types both parentheses automatically and puts the cursor between them.
  - Dialogue: the speech.
  - Transition: uppercase (CUT TO: etc.).
  - Shot: uppercase; paginates like a scene heading (no orphans) but is not numbered; use instead of a heading when a slug must not get a number.
  - Cast List: sitcom/multi-cam list of characters in the scene, placed under the heading and auto-maintained as characters speak or are removed; non-speaking characters can be added; order alphabetical / appearance / custom. Tag **later** (but **v1 for import**: keep the paragraph).
  - Core elements cannot be renamed or deleted; custom elements can be added (they start as a copy of Action) and deleted.
- **TV/act elements**: New Act, End of Act, Sequence appear in default shortcut list and Return flow (New Act → Scene Heading; End of Act → New Act). Ver ≤11. Tag **v1** (needed to import TV scripts faithfully) — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.26.1, §1.26.3.
- **Outline elements**: Summary, Outline 1, Outline 2, Outline 3, Note (more can be created); default text colour blue; can be hidden from screen/print (hiding changes page count); Tab cycles Outline 1→2→3→Note; Return after an outline paragraph gives a Summary at the same indent (dynamic indent added 12.0.5). Ver 12 (Outline elements tied to Outline Editor). Tag **v1 for import/preserve**, **later** for UI — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.16.7; [FD12 notes](https://update.finaldraft.com/12/0/release_notes.html).
- **Default Return (Enter) transitions**: General→General; Scene Heading→Action; Action→Action; Character→Dialogue; Dialogue→Action; Parenthetical→Dialogue; Transition→Scene Heading; Shot→Action; Cast List→Action; New Act→Scene Heading; End of Act→New Act; Summary→Summary. Return on an empty paragraph opens an element picker (choose by mouse, first letter or arrows). Tag **v1** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.26.1.
- **Default Tab transitions**: Scene Heading→Action; Action→Character; Character→Transition (only when the character paragraph is empty); Transition→Scene Heading; Dialogue→Parenthetical; Parenthetical→Dialogue; Outline 1→2→3→Note→Note. Inside a scene heading Tab advances intro → location (inserting ". ") → time (inserting " - ") and opens the next SmartType list. Tab also accepts the current SmartType suggestion. In card/scene views Tab moves between editable heading/summary/title fields. Tag **v1** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.26.2.
- **Element shortcuts** (Mac Cmd / Win Ctrl): 0 General, 1 Scene Heading, 2 Action, 3 Character, 4 Parenthetical, 5 Dialogue, 6 Transition, 7 Shot, 8 Cast List, 9 New Act; with Control: 8 Sequence, 9 End of Act, 0 Summary, 1–3 Outline 1–3, 4 Note. Cmd+Option+number converts the current paragraph instead of creating one. Core shortcuts are fixed; custom elements may get user shortcuts. Tag **v1** (number-key element switching) — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.26.3, §1.24.1.
- **Auto-behaviours**: typing "int." or "ext." at the start of an Action paragraph converts it to a scene heading (Tag **v1**); first word of each sentence auto-capitalised (preference; Tag **v1**); uppercase-by-element via element Caps setting (Tag **v1**); list continuation — a line started with *, -, --, ... or • repeats the mark on Return and an empty marked line removes it (FD13; Tag **later**); smart quotes option in Page Layout (Tag **v1**) — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.26.5, §1.4.2.1, §1.16.9, §1.11.1.3.
- **Character continueds**: automatic "(CONT'D)" after the cue when the same character resumes speaking after an intervening non-dialogue element within a scene (not across scenes); on by default; toggle in Mores and Continueds. Tag **v1** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.11.3, §1.17.1.
- **Extensions**: typed with "(" after the name, which pops the Extensions list (O.S., V.O., etc.); an option makes Tab after a character open an extension instead of a parenthetical. Tag **v1** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.16.1, §1.25.8.
- **SmartType lists**: Characters, Character Extensions, Scene Intros, Locations, Times, Transitions. Behaviour: popup filters as you type with the rest of the top match ghosted; accept with Return/Tab/double-click; repeated first letter cycles; new entries are learned automatically when typed; manual New/Edit/Delete in the dialog (editing a list does not touch the script); Rebuild resyncs lists to script content (and reports depend on lists, so rebuild first); Alphabetize or drag to reorder. Options: per-list matching on/off (characters, scene headings, transitions), "guess next character" in two-hander exchanges, Tab→extension, show popup window, list order alphabetical/custom, auto-position popup near caret, sort characters by dialogue count, ghost-text colour. Scene-intro and time **separators** are configurable (defaults "." and "-"). Ver ≤11. Tag **v1** core (lists, autocomplete, learn, rebuild, guess-next-character); **later** the cosmetic options — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.25, §1.11.6.
- **Macros**: built-in Option/Alt+number macros insert common strings (INT., EXT., - DAY, CUT TO: …), each with a "macro element" (what paragraph to create first, without splitting) and "transition to" (element after insertion); only two fully custom slots (Option+0, Option+Shift+0); names show in status bar. Ver ≤11. Tag **later** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.11.7.
- **Reformat**: single paragraph via toolbar dropdown / Change Element To / Cmd+Option+number; batch "Reformat" palette that walks paragraphs and assigns elements by number key with Next/Previous/Delete. Ver ≤11. Tag **v1** single-paragraph; **later** batch palette (valuable after PDF/TXT import) — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.24, §1.12.8.

### Inferences
- The Return/Tab tables plus SmartType define the "feel" users will judge a clone by; they should be data-driven per template (FD stores "next element on Return" per element, and the Tab table is fixed in the docs except for the Tab→extension option).
- The status-bar hint of what Tab/Return will produce is a low-cost, high-value discoverability aid worth copying in v1.

### Gaps
- The docs give default Tab transitions only for screenplay core elements; whether Tab from New Act / End of Act / Cast List does anything is not stated.

## Q6. Format > Elements settings and Document > Page Layout / breaking rules

### Takeaway
Each element has: name; behaviour (start new page, paginate-as rule); shortcuts (Cmd/Ctrl key and "next element on Return"); font (family, size, style, colour; "apply font/size to all"); paragraph (alignment left/centre/right/justified, line spacing 1/1.5/2/3, space before 0–30 lines, left/right indent in inches from the page edge); caps (implicit — core elements like headings/characters/transitions/shots are uppercase). Page Layout holds top/bottom text margins, header/footer margins, paper (US Letter or A4, stored per script), colours, document line-spacing (Very Tight/Tight/Normal/Loose), smart quotes, and "break dialogue and action at sentences". All of this is **v1**, because pagination depends on it.

### Cited Findings
- **Elements dialog — Basic tab**: element list (core + custom; New, Delete custom only); **Start New Page** (e.g. every scene on its own page); **Paginate As** (borrow another element's page-break rules or None — e.g. a Lyrics element paginating as Dialogue so it never separates from its cue); **Shortcut key** (+ optional Control modifier; core shortcuts fixed; OS-reserved combos refused); **Next Element on Return**. Ver ≤11. Tag **v1** — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.17.3.
- **Font tab**: font + size via Set Font; Apply Font/Size to All Elements (does not apply styles). FD strongly advises its own metric-stable Courier ("Courier Final Draft", 12 pt) because other fonts — even other Couriers — change page counts across machines. Tag **v1** (ship a metric-compatible, freely licensed Courier-style font; do not use FD's font) — §1.17.3, §1.9.6; [Glossary](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) "Courier Final Draft".
- **Paragraph tab**: Alignment (Left, Centered, Right, Justified); Spacing (1, 1.5, 2, 3); Space Before (0, 1, 2, Other up to 30); Left/Right Indents in inches from the left page edge. Tag **v1** — §1.17.3.
- Local overrides: per-paragraph ruler indents, Format > Spacing / Space Before / Alignment, Leading (Loose/Normal/Tight/Very Tight on a selection, used to "cheat" a page); Revert Paragraph restores element defaults. Tag **v1** for preserving overrides on import; **later** UI for leading cheats — §1.8.11, §1.9.13–1.9.16, §1.16.4.
- **Apply a Template** inside the Elements dialog (convert e.g. feature → one-hour by importing element specs from a template or any script). Tag **later** — §1.17.3.
- **Page Layout > Margins**: Text margins top/bottom in inches (US Screenplay default 1.0" each), auto-adjusted to avoid overlapping header/footer; Header/Footer margins (default 0.5"); warning if below printer's hardware margins; **Paper type US Letter or A4** saved with the script. (Left/right margins are not page settings — they come from element indents.) Tag **v1** — §1.11.1.1.
- **Page Layout > Colors**: page background, text, invisibles (defaults white/black/grey), per script; kept in PDF if Keep Colors is ticked; not visible in Night/Midnight. Tag **later** — §1.11.1.2.
- **Page Layout > Options**: document **Line Spacing** Very Tight / Tight / Normal / Loose (a 100-page Normal script ≈ 90 / 95 / 107 pages; Normal recommended for the page-a-minute convention); **Enable Smart Quotes**; **Break Dialogue and Action at Sentences** (when on, a page break may only fall between sentences; when off, text may split mid-sentence at line end). Tag **v1** (line spacing presets, smart quotes, sentence breaking) — §1.11.1.3.
- **Built-in breaking rules** documented in prose: scene headings and shots are never stranded at a page bottom; dialogue is kept with its cue and continued with (MORE)/(CONT'D) when it must split; scenes split with CONTINUED markers when enabled; Paginate-As lets custom elements inherit those rules; forced page breaks via Insert > Page Break (users told not to use blank lines). FD frames a character cue at the bottom of one page with dialogue on the next as the widow/orphan case it prevents. Tag **v1** — §1.17.1, §1.11.3, §1.16.4, §1.10.4.
- No user-facing "lines per inch" or "lines per page" setting is documented; vertical density is controlled by the four line-spacing presets plus per-selection leading. — §1.11.1.3, §1.9.16.

### Inferences
- To reproduce FD page counts, a clone needs (a) the same indents/spacing per element from the template, (b) a font with identical advance widths and line height, (c) the four line-spacing presets' exact line heights, and (d) the keep-with-next/orphan/sentence-break rules. (c) and the precise orphan thresholds (minimum lines of dialogue/action before a break) are not documented and will need empirical calibration against PDFs of public-domain or self-authored test scripts.
- The ruler is inches-only in FD; a clone can offer metric display but should store FDX-compatible inch values.

### Gaps
- Exact numeric line heights for Very Tight/Tight/Normal/Loose, and minimum-lines rules for splitting action/dialogue across pages, are not given in the docs.
- Default indent values per element for each template are shown only in screenshots/templates (not transcribed; must be derived from public screenplay-format conventions instead).

## Q7. Import / export and printing

### Takeaway
Officially FD13 opens .fdx/.fdxt, legacy .fdr/.fdt (FD5–7), .txt, .rtf, .fcf, and text-based PDF (FD12+); it does **not** list Fountain, Celtx, Movie Magic Screenwriter or Word .docx — users are told to export those to PDF (best) or TXT/RTF and let FD reformat. Exports: .fdx, .fdxt, PDF, RTF, TXT, text-with-layout TXT, HTML, .fcf, scheduling (.sex), Avid TXT, tab-delimited dialogue, Beat Board PDF, Navigator CSV, reports as documents.

### Cited Findings
- KB import list: PDF (FD12/13 only), TXT, RTF, FCF; other programs' scripts should be exported to PDF (FD12/13) or TXT/RTF (FD11 and older) and opened as a Script; on Windows set file type to All. — [KB: What file formats can I import](https://kb.finaldraft.com/hc/en-us/articles/15575252515988-What-file-formats-can-I-import-into-Final-Draft).
- PDF import must be text-based (not scanned); FD12/13 import PDFs "with no or very little loss of formatting". — [FD download FAQ](https://www.finaldraft.com/download/); [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) §1.5.3; PDF import introduced 12.0.0 per [FD12 notes](https://update.finaldraft.com/12/0/release_notes.html).
- Text import: FD reformats into the default screenplay template; guide recommends PDF first, plain text second; afterwards use Reformat. Text-file import improvements in 11.0.2. — §1.16.2; [FD11.0 notes](https://update.finaldraft.com/11/0/release_notes.html).
- FDX is described by FD as its default XML-based format. — [FD13-Mac guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-mac-exported.pdf) Glossary "FDX", "XML".
- Export list (Mac): .fdx, .fdxt, .fcf, HTML, RTF, TXT, Scheduling (.sex for EP Scheduling), Text with Layout, Avid script-based editing, Tab-delimited dialogue; Windows list adds PDF; Movie Magic Scheduling 5+ reads .fdx directly. — §1.5.10; [FD13-Win guide](https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf) §1.5.2.
- Other outputs: Beat Board → PDF; Navigator tabs → CSV; reports → editable docs that can be exported (FDX/RTF/PDF); index-card printing; print options listed in Q1 (ranges, revision-set filters, character sides, keep colours, title page, back-to-front). — §1.5.10, §1.19.1.4, §1.19.3.3, §1.20.2.2, §1.5.15.
- Combine Files works only with FDX. ScriptCompare compares two scripts. — §1.12.6, §1.12.10.
- Final Draft Go (iOS) opens the same FDX files with no special handling; syncs through Dropbox/iCloud. — [FD download FAQ](https://www.finaldraft.com/download/); [FD Go page](https://www.finaldraft.com/products/final-draft-iphone-ipad/).
- Tags: **v1** — FDX import/export with high fidelity (elements, custom element definitions, page layout, header/footer, title page, scene numbers, omitted scenes, revisions, locked pages, dual dialogue, alts, ScriptNotes, bookmarks, scene metadata, tags, beats/outline — at least preserved verbatim if not editable), PDF export (with title page, revision colours/marks, scene numbers, mores/continueds), Fountain import/export (open standard, not offered by FD — a differentiator), plain-text export; **later** — PDF import (hard; FD itself took until v12), TXT/RTF import with reformat heuristics, RTF/HTML export, CSV exports, tab-delimited dialogue, .fdxt template import, index-card print; **skip** — .fdr/.fdt legacy binary (explicitly out of scope), .fcf, .sex, Avid TXT, Celtx/Movie Magic Screenwriter native formats (FD itself routes these via PDF/TXT).

### Inferences
- Because FD does not import Fountain, Celtx or MMS natively, an open-source app that imports FDX **and** Fountain already covers the practical interchange paths screenwriters use; PDF import is the main capability gap to schedule post-v1.

### Gaps
- No official page specifies RTF/HTML export fidelity or the exact column layout of the tab-delimited dialogue file beyond the listed fields.
- The FDX schema itself is not documented in the user guides (separate research).
